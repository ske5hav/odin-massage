# Mini Message Board

A simple Mini Message Board built using **Node.js, Express.js, and EJS**. Users can create messages by entering a title and message, which are saved as text files and displayed on the homepage.

## Features
- Create messages with a title and content
- Store messages in text files using the Node.js `fs` module
- Display saved messages on the homepage
- Delete message files
- Simple black-and-white user interface

## Technologies Used
- Node.js
- Express.js
- EJS
- Tailwind CSS
- File System (`fs`) module

## How to Run

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the server:

   ```bash
   node index.js
   ```

4. Open `http://localhost:3000` in your browser.
